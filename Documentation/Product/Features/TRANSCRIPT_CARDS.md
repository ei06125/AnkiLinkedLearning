# Transcript cards

Temporarily capture the current Japanese LinkedIn Learning transcript. A new capture replaces it and transcripts are not persisted. Switch between compact Words and Individual kanji tabs, select a target, or highlight text manually while retaining its complete surrounding sentence. Target selection also highlights matches in LinkedIn’s visible transcript when its current page structure allows it. Closing the panel removes those page highlights; selecting a target restores them.

Card front: kanji and sentence. Card back: kanji, reading, sentence, translation, and lesson source. Export UTF-8 text for Anki Desktop without an add-on.

Multi-character word readings and English glosses are retrieved from Jisho. Selected card sentences are translated automatically through MyMemory. Readings and translations remain editable, failed translations can be retried, and existing cards with blank translations are backfilled when the panel opens. Only the selected word and selected card sentence are sent to their respective services. Live extraction is verified against an authenticated LinkedIn Learning lesson; pasted transcripts provide a fallback.

The deck builder displays only the card currently being created or edited while retaining the full saved-card count for export. Exported files use Chrome’s configured download folder, which can be opened from the panel.
