Install & use

Run npm run build in the project folder. In Chrome, open chrome://extensions, enable Developer mode, choose Load unpacked, and select the generated .build/extension folder. Click the extension icon while viewing a LinkedIn Learning lesson.

Capture each lesson you want to study. If capture cannot find the transcript, use the paste option. No account, API key, or Anki add-on is needed.
